# Zefi Immobilien

Website for Zefi Immobilien GmbH, built with React 19 and Vite 7.

## Run locally

Use Node.js 22.12 or newer.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

```sh
npm run build
npm run preview
```

The production build is generated in `dist/`.

## Website

German-language responsive website with services, company introduction, collaboration process, native expandable FAQs, mobile navigation, and direct phone and email contact links.

Contact links open the phone or email application. No backend is connected. The older, unused Gewinnspiel component is not part of the active page.

Photography is illustrative and loaded from Unsplash. Fonts are loaded from Google Fonts. An internet connection is needed for these external assets. Business details are retained from the original project; review the copy and required legal information before public launch.
